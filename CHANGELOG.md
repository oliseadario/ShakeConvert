# Changelog

## 1.1.0

- **250+ formats.** Data (JSON, YAML, TOML, XML), markup (pandoc), e-books and comics, subtitles, archives (7-Zip), DXF CAD, 3D models, fonts, maps, email, CorelDRAW/Visio vectors, Live Photos, and rare documents through LibreOffice.
- **New outputs.** Images → HEIC, JPEG XL, JPEG 2000, TGA, QOI and traced SVG. PDF → TIFF, SVG, EPUB, CBZ. Video → APNG, still frame, subtitles. Audio → WavPack, TTA, W64, AC3, E-AC3.
- **More slice.** Browse every format one page at a time. The slice fills up to show when it's about to flip.
- **Settings → Formats in the ring.** Turn each output format on or off, by category.
- **English and Italian.** Follows the Windows display language automatically.
- **Redesigned settings window** with a custom title bar.

## 1.0.0 — first public release

- Windows 11-style pie menu that opens when you shake the mouse while dragging a file.
- Acrylic glass that follows light/dark theme, accent color and Windows *Transparency effects*.
- Local conversions for images (including PSD, RAW, HEIC, WEBP, AVIF, SVG), PDF, Word, Excel, PowerPoint, text, audio and video.
- Editable PDF → Word and PDF → Excel with ready-to-use tables, offline (pdf2docx). Windows OCR for scans.
- Clip Studio Paint → full-resolution images (layers rebuilt locally).
- InDesign → PDF/JPG/PNG through InDesign, when installed.
- Notifications with real progress and cancel. Settings with the Mica material.
- Per-user installer with no admin rights. No data collection.
